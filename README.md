## 📖 About

This repository contains basic Java programming concepts, examples, and practice programs designed for beginners. It provides a structured learning path to help you understand core programming concepts and build a solid foundation in Java.

- Java Syntax and Structure
- Variables and Data Types
- Operators and Expressions
- Conditional Statements
- Loops and Iteration
- Arrays
- Strings
- Methods (Functions)
- Object-Oriented Programming Basics
- Problem-Solving Techniques

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or higher
- Any IDE (IntelliJ IDEA, Eclipse, NetBeans, VS Code)

### Check Java Installation

```bash
java --version
```

or

```bash
javac --version
```

### Clone the Repository

```bash
git clone https://github.com/samira-haque/Basic_Java.git
cd Basic_Java
```

### Compile and Run

Compile:

```bash
javac FileName.java
```

Run:

```bash
java FileName
```
